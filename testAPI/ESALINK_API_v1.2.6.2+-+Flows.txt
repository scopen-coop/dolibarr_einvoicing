    ## FLOWS Api


    The __Flow Service__ API allows to:

     >- upload a flow.
     >- retrieve information related to a set of flows.
     >- download a flow given its identifier


    The resources of the API are :

     >- `/flows` : with creation and retrieval methods.

    Worflow example:

     >- `POST /v1/flows` : provide the flow information & content
     >- `POST /v1/flows/search` : retrieve flows given multiple criterias.
     >- `GET /v1/flows/{id}` : download a flow based on its id.


     
     __Flows api are not functional APIs__, they're technical. A `GET` on a flow does not gives you the functional status of an invoice (`ok` at this point only says that the file you sent to the platform "can be read"). To know the functional status of your invoice sent, you __MUST__ get all the LifeCycle XML files available to you on the API, get them and read them.
